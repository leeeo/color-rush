## 1. 이 프로젝트는 무엇인가요

**Color Rush(컬러 러시)**는 Flutter로 만든 반응속도 게임입니다. 화면에 색깔을 뜻하는 단어가 나타나고, 그 단어가 표시된 잉크 색이 단어의 "뜻"과 같은지 다른지를 순간적으로 판단해서 ✓ 또는 ✗ 버튼을 누르는 게임입니다(심리학에서 말하는 스트룹 효과를 이용한 게임입니다). 점수가 오를수록 제한 시간이 점점 짧아져서 나중에는 정말 빠르게 반응해야 합니다.

이미 다음이 완성되어 있습니다.

- 게임 로직, 화면, 다국어(한국어/영어) 지원
- AdMob 광고(배너, 전면, 보상형) 연동과 GDPR 동의(UMP), iOS ATT 구현
- 인앱 결제(광고 제거 상품) 연동
- 자동 테스트 9개 (전부 통과 상태)
- 정적 HTML 마케팅 웹사이트
- GitHub Actions 기반 CI/CD 워크플로 3종

즉, **개발은 끝난 상태**이고 지금부터 할 일은 "내 컴퓨터에서 실행해보고 → 내 계정 정보로 채워넣고 → 스토어에 올리고 → 광고/마케팅을 자동화"하는 과정입니다. 이 문서들은 그 과정을 화면 단위로 안내합니다.

## 4. 필요한 계정과 비용

출시를 위해 아래 계정들이 필요합니다. 미리 가입해두면 나중에 심사 대기 시간을 줄일 수 있습니다.

| 계정 | 비용 | 용도 | 가입 URL |
|---|---|---|---|
| Google Play Console | **$25 (1회, 평생)** | Android 앱 출시 | https://play.google.com/console/signup |
| Apple Developer Program | **$99/년** | iOS 앱 출시 | https://developer.apple.com/programs/enroll/ |
| AdMob | 무료 (Google 계정과 연동, Google 애드센스 연계) | 광고 수익화 | https://admob.google.com/ |
| GitHub | 무료 | 소스 코드 저장, CI/CD, 웹사이트 배포 | https://github.com/signup |

- Google Play Console 비용은 계정당 1회만 내면 되고, 매년 갱신할 필요가 없습니다.
- Apple Developer Program은 매년 자동 갱신되는 연간 구독입니다. 갱신을 원치 않으면 만료 전에 해지하면 됩니다.
- 이 두 스토어의 가입 절차, 필요 서류(신분증 등), 정책은 시기에 따라 바뀔 수 있습니다. 가입 직전에는 반드시 위 공식 URL에서 최신 안내를 확인하세요.

## 5. macOS가 없다면? (iOS 빌드 관련 중요 안내)

iOS 앱을 빌드하려면 Xcode가 필요하고, Xcode는 **macOS에서만** 실행됩니다. Mac이 없어도 괜찮습니다. 다음 두 가지 방법 중 하나를 쓰면 됩니다.

1. **GitHub Actions의 macOS 러너 사용**: GitHub Actions는 `runs-on: macos-latest` 로 지정하면 클라우드에 있는 Mac에서 빌드해줍니다. (분당 비용이 발생하니 09번 문서의 안내를 참고하세요.)
2. **Codemagic 사용**: Flutter 전용 CI 서비스로, 개인 계정 기준 매달 macOS 빌드 500분을 무료로 제공합니다. 대부분의 개인 프로젝트는 이 무료 한도 안에서 충분합니다.

두 방법 모두 09번 문서(CI/CD 자동화)에서 더 자세히 다룹니다.
