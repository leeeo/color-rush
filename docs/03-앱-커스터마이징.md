# 03. 앱 커스터마이징

**문서 목적**: 게임 난이도, 색상, 문구, 광고 정책, 아이콘, 앱 이름, 패키지명을 내가 원하는 대로 바꾸는 방법을 안내합니다.

✅ **선행 조건**
- [ ] [02-앱-실행-및-테스트.md](02-앱-실행-및-테스트.md) 완료 (앱이 정상적으로 실행됨을 확인)
- [ ] Python 3.14 설치 확인 (`python --version`, 아이콘 재생성 시 필요)

⏱ **예상 소요 시간**: 20~40분 (원하는 항목만 골라서 수정하면 더 짧게)

---

## 1. 게임 컨셉 이해하기

Color Rush는 스트룹 효과(Stroop effect)를 이용한 반응속도 게임입니다. 화면에 색깔 단어(예: "파랑")가 나타나고, 그 글자가 어떤 잉크 색으로 칠해져 있습니다. 플레이어는 단어의 **뜻**과 **잉크 색**이 같은지 판단해서 같으면 ✓(일치), 다르면 ✗(불일치)를 누릅니다.

점수가 오를수록 제한 시간이 점점 짧아집니다. 정확히는 점수 1점당 30ms씩 빨라지고, 아무리 빨라져도 850ms보다 짧아지지는 않습니다. 이 문서에서는 이 수치들을 포함해 바꿀 수 있는 모든 지점을 안내합니다.

## 2. 난이도 조정

파일: `app\lib\game\game_logic.dart`

```dart
static const int baseTimeMs = 2000;  // 첫 라운드(점수 0)에 주어지는 시간
static const int minTimeMs = 850;    // 아무리 빨라져도 이 시간보다 짧아지지 않음
static const int stepMs = 30;        // 점수 1점마다 줄어드는 시간
```

- 게임을 더 쉽게 만들고 싶다면 `baseTimeMs`를 늘리거나 `stepMs`를 줄이세요.
- 더 어렵게(더 빨리 극한 속도에 도달하게) 만들고 싶다면 `stepMs`를 늘리거나 `minTimeMs`를 줄이세요.

## 3. 색상 팔레트 변경

파일: `app\lib\core\app_colors.dart`

배경색, 텍스트 색, 정답/오답 색, 6가지 게임 색상(빨강/파랑/초록/노랑/보라/주황)이 모두 이 파일에 정의되어 있습니다. `Color(0xFF......)` 형식의 16진수 값을 원하는 색으로 바꾸면 됩니다.

> 주의: 이 파일 상단 주석에 "website/style.css와 동기화 유지"라고 적혀 있습니다. 브랜드 색을 바꾼다면 웹사이트 쪽 색상도 함께 맞춰주는 것이 좋습니다.

## 4. 문구/번역 수정

파일: `app\lib\core\strings.dart`

한국어(`S.ko`)와 영어(`S.en`) 두 세트로 앱에 쓰이는 모든 문구가 정의되어 있습니다. 앱 이름, 태그라인, 버튼 텍스트, 게임 방법 설명, 색상 이름 등을 여기서 수정합니다. 두 언어 모두 같은 항목 개수를 유지해야 컴파일 오류가 나지 않습니다(하나의 `S` 클래스가 두 인스턴스를 갖는 구조입니다).

## 5. 광고 정책 수치 조정

파일: `app\lib\monetization\ad_config.dart`

```dart
static const Duration interstitialCooldown = Duration(seconds: 60);
static const int interstitialEveryNGameOvers = 3;
```

- `interstitialCooldown`: 전면 광고를 최소 이 시간 간격으로만 보여줍니다(너무 자주 보여줘서 사용자 경험이 나빠지는 것을 방지).
- `interstitialEveryNGameOvers`: 게임 오버가 이 횟수만큼 발생할 때마다 한 번씩만 전면 광고를 보여줍니다(현재는 3회당 1회).

이 값을 바꾸면 광고 노출 빈도가 바뀌어 수익과 사용자 경험(그리고 무효 트래픽 위험)의 균형이 달라집니다. 자세한 최적화 팁은 [10-마케팅-자동화.md](10-마케팅-자동화.md)를 참고하세요.

## 6. 앱 아이콘 재생성

아이콘은 코드로 그려지는 방식입니다(별도 이미지 파일을 직접 그릴 필요가 없습니다).

1. `scripts\make_icon.py` 파일을 열어 색상(`COLORS` 리스트)이나 배경색(`BG`), 모양을 원하는 대로 수정합니다.
2. 아이콘 이미지를 다시 생성합니다.

```powershell
python scripts\make_icon.py
```

이 명령은 `app\assets\icon\icon.png` 와 `app\assets\icon\icon_foreground.png` 두 파일을 새로 만듭니다.

3. 생성된 이미지를 실제 앱 아이콘(Android/iOS 각 해상도)으로 반영합니다.

```powershell
cd app
dart run flutter_launcher_icons
```

## 7. 앱 표시 이름(런처에 보이는 이름) 변경

앱스토어 등록명이 아니라, 홈 화면 아이콘 아래에 표시되는 이름을 바꾸려면 아래 두 파일을 수정합니다.

- **Android**:
  - `app\android\app\src\main\res\values\strings.xml` (영어/기본 로케일용, 현재 `Color Rush`)
  - `app\android\app\src\main\res\values-ko\strings.xml` (한국어 로케일용, 현재 `컬러 러시`)
- **iOS**: `app\ios\Runner\Info.plist` 안의 `CFBundleDisplayName` 키 (현재 `Color Rush`)

## 8. 패키지명(번들 ID) 변경 시 주의사항

현재 패키지명(Android)/번들 ID(iOS)는 `com.leeeo.colorrush` 입니다.

★ **이 값은 스토어에 앱을 처음 등록하기 "전"에만 자유롭게 바꿀 수 있습니다.** 한 번 스토어에 등록하고 나면 패키지명은 절대 변경할 수 없습니다(새 앱으로 다시 등록해야 합니다).

바꾸고 싶다면 아래 두 곳을 **함께** 수정해야 합니다. 둘 중 하나만 바꾸면 빌드가 깨지거나 두 값이 어긋납니다.

- Android: `app\android\app\build.gradle.kts` 안의 `namespace`와 `defaultConfig.applicationId` 두 값 모두
- iOS: Xcode의 Bundle Identifier (Runner 프로젝트 설정, 07번 문서에서 다룹니다)

## 9. 건드리면 안 되는 빌드 값

- `app\android\app\build.gradle.kts`의 `minSdk`는 **24 미만으로 낮추면 안 됩니다.** google_mobile_ads(AdMob) 9.x가 최소 Android 7.0(API 24)을 요구해서, 낮추면 "uses-sdk:minSdkVersion" / manifest merger 류의 빌드 오류가 납니다. 현재는 Flutter 기본값(`flutter.minSdkVersion`)이 정확히 24로 해석되므로 그대로 두면 됩니다.
