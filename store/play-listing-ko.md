# Google Play 스토어 등록정보 (한국어)

그대로 복사해 Play Console > 스토어 설정 > 스토어 등록정보에 붙여 넣으세요.
글자 수는 작성 시점에 Play 제한 내로 검증했습니다(제목 30 / 짧은 설명 80 / 전체 설명 4000).

## 앱 이름 (17/30)

```
컬러 러시 - 반응속도 두뇌게임
```

## 짧은 설명 (44/80)

```
색과 글자가 다른 순간, 0.8초 안에 판단! 무료 반응속도 두뇌 트레이닝 게임
```

## 전체 설명 (634/4000)

```
컬러 러시(Color Rush)는 단어의 '뜻'과 '잉크 색'이 일치하는지 순간적으로 판단하는 스트룹 효과 기반 반응속도 게임입니다.

규칙은 단 하나. 화면에 뜬 단어의 의미와 글자 색이 같으면 O, 다르면 X. 머리로는 쉬워 보이지만, 제한 시간은 1초도 되지 않습니다.

■ 이런 게임입니다
· 판단 한 번에 0.8초 — 순발력과 집중력을 동시에 씁니다.
· 라운드가 진행될수록 제한 시간이 짧아지는 가속 구조
· 한 손으로 즐기는 세로 화면, 한 판은 1분 이내
· 정답/오답 진동 피드백 (설정에서 끌 수 있습니다)
· 한국어·영어 지원, 기기 언어에 맞춰 자동 전환
· 인터넷 없이 오프라인 플레이, 로그인·회원가입 불필요

■ 이런 분께 추천합니다
· 출퇴근길 짧은 시간에 두뇌를 깨우고 싶은 분
· 반응속도, 순발력, 집중력을 측정하고 기록을 깨고 싶은 분
· 복잡한 튜토리얼 없이 바로 시작하는 캐주얼 게임을 찾는 분

■ 광고와 결제
· 무료로 모든 기능을 이용할 수 있습니다.
· 게임 오버 후 광고를 보면 그 자리에서 이어서 플레이할 수 있습니다.
· 광고 없이 즐기고 싶다면 인앱 구매(광고 제거)를 한 번만 결제하면 됩니다.

지금 설치하고, 당신의 뇌가 색과 글자 중 무엇에 먼저 반응하는지 확인해보세요.
```

## 함께 입력하는 값

| 항목 | 값 |
|---|---|
| 카테고리 | 게임 > 캐주얼 (대안: 퍼즐) |
| 태그 | 두뇌 게임, 반응속도, 캐주얼 |
| 개인정보처리방침 URL | https://leeeo.github.io/color-rush/privacy.html |
| 웹사이트 | https://leeeo.github.io/color-rush/ |
| 광고 포함 | 예 (배너·전면·보상형) |
| 인앱 구매 | 예 (`remove_ads`, 광고 제거) |
| 타겟 연령 | 13세 이상 |
