# Google Play 스토어 등록정보 (한국어)

그대로 복사해 Play Console > 스토어 설정 > 스토어 등록정보에 붙여 넣으세요.
Play 제한: 제목 30 / 짧은 설명 80 / 전체 설명 4000자. 붙여 넣은 뒤 콘솔의 글자 수 표시로 다시 확인하세요.

수치 근거: 제한 시간은 `app/lib/game/game_logic.dart`(2.0초에서 점수당 0.03초씩 줄어 0.85초에서 멈춤),
광고 빈도는 `app/lib/monetization/ad_config.dart`(게임 오버 3회마다, 60초 쿨다운)를 따릅니다. 값을 바꾸면 문안도 함께 고치세요.

## 앱 이름

```
컬러 러시 - 반응속도 두뇌게임
```

## 짧은 설명

```
글자 뜻과 색이 같을까, 다를까? 짧은 순간에 고르는 반응속도 게임
```

## 전체 설명

```
화면에 '빨강'이라는 글자가 파란색으로 떠 있습니다. 뜻과 색이 같으면 ✓, 다르면 ✗를 누르면 됩니다. 규칙은 이게 전부인데, 막상 해 보면 손이 생각보다 먼저 나갑니다.

처음에는 한 문제에 2초가 주어집니다. 맞힐 때마다 조금씩 짧아져서, 점수가 쌓이면 1초도 안 되는 시간 안에 골라야 합니다. 한 번 틀리면 게임이 끝납니다.

이런 점을 신경 써서 만들었습니다.
- 세로 화면이라 한 손으로 할 수 있습니다.
- 정답과 오답을 진동으로 알려 줍니다. 진동은 설정에서 끌 수 있습니다.
- 한국어와 영어를 지원하고, 기기 언어에 맞춰 바뀝니다.
- 로그인이나 회원가입 없이 바로 시작합니다. 최고 기록은 기기에만 저장됩니다.
- 게임은 인터넷 없이도 할 수 있습니다. 광고는 인터넷에 연결돼 있을 때만 나옵니다.

광고와 결제 안내
- 모든 기능을 무료로 쓸 수 있고, 화면 아래에 배너 광고가 나옵니다.
- 게임 오버가 세 번 쌓이면 전면 광고가 한 번 나올 수 있습니다. 1분 안에 다시 나오지는 않습니다.
- 게임 오버 화면에서 광고를 끝까지 보면 그 판을 이어서 할 수 있습니다.
- 광고가 싫다면 '광고 제거'를 한 번 구매하면 됩니다. 이어하기용 광고는 원할 때만 볼 수 있습니다.

문의: hello@leeeo.app
```

## 함께 입력하는 값

| 항목 | 값 |
|---|---|
| 카테고리 | 게임 > 캐주얼 (대안: 퍼즐) |
| 태그 | 캐주얼, 두뇌 게임, 반응속도 |
| 이메일 | hello@leeeo.app |
| 개인정보처리방침 URL | https://leeeo.github.io/color-rush/privacy.html |
| 웹사이트 | https://leeeo.github.io/color-rush/ |
| 광고 포함 | 예 (배너·전면·보상형) |
| 인앱 구매 | 예 (`remove_ads`, 광고 제거) |
| 타겟 연령 | 13세 이상 |
